# Как обновить Trellis без потери данных

Всё ваше хранится в папке `data`: документы и кейсы, чаты, результаты и архив анализов, замечания к документации, черновики рабочего места, настройки, ключи и токены (зашифрованы). Обновление меняет программу, а `data` не трогает.

## Обычное обновление (папка из git)

1. Закройте окно Trellis (то, где работает `start.cmd`).
2. Дважды щёлкните `update.cmd`.
3. Когда появится «✓ Готово», запустите `start.cmd`.

Что делает `update.cmd`:
1. Копирует `data` в `data-backups\<дата>-before-update-…`.
2. Загружает новую версию (`git pull`) и ставит зависимости.
3. Переводит данные в новый формат, если он изменился.
4. Показывает, что нового.

Если какой-то шаг не прошёл, данные остаются как были, а копия уже сделана.

## Новая версия пришла архивом (zip)

1. Распакуйте архив в **новую** папку. Старую пока не удаляйте.
2. Откройте в новой папке командную строку и выполните:
   ```
   update.cmd --from "C:\путь\к\старой\папке"
   ```
3. Запустите `start.cmd` в новой папке. Когда убедитесь, что всё на месте, старую папку можно удалить.

## Если что-то пошло не так

Резервные копии лежат в `data-backups`. Чтобы их посмотреть, выполните:
```
npm run data -- list
```
Чтобы вернуть одну из них (текущая `data` перед этим тоже сохранится в копию), выполните:
```
npm run data -- restore <имя копии>
```
Ручная копия в любой момент: `npm run data -- backup "перед экспериментом"`.

## Если `update.cmd` пишет…

- **«Trellis запущен»**: закройте окно приложения и повторите.
- **«Изменены файлы приложения»**: кто-то правил код в этой папке. Сохраните изменения отдельно или выполните `git stash`, затем повторите.
- **«Нужен Node.js 22.13 или новее»**: установите свежий Node.js LTS с nodejs.org.
